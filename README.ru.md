# Algorithms

[English](README.md) · [Русский](README.ru.md)

Решения алгоритмических задач с подробными объяснениями логики и пошаговыми визуализациями.

## Возможности

- Сортировки: квадратичные, подсчётом, быстрая, k-я порядковая статистика
- Бинарный поиск, в том числе по ответу
- Рекурсия и динамическое программирование
- Структуры данных: стек, очередь, дек, куча
- Графы: обходы (BFS, DFS), алгоритм Дейкстры, топологическая сортировка

## Использование

Каждая тема лежит в отдельной папке. Откройте папку, чтобы увидеть задачи, решения и пояснения.
